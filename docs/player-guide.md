# 玩家指南：用 HMCL / PCL2 / Prism Launcher 外置登录

> 本指南面向**玩家**：用你在服务器社区网站注册的账号，直接登录 Minecraft 并进服。
> 服主侧部署见 [`deploy.md`](deploy.md) 与 [`deploy-windows.md`](deploy-windows.md)。

## 开始之前

1. **先在网站注册账号**：打开服务器社区网站（服主给你的地址），点「注册」，填邮箱和密码。
   如果注册后要求验证邮箱，去收件箱点验证链接；收不到邮件时联系服主（服主侧邮件
   配置问题，玩家侧无法解决）。
2. **拿两样东西**（都可以在网站的「游戏账号管理」页找到）：
   - **认证服务器地址**：形如 `https://auth.example.com/api`（API 根，页面上有
     「复制地址」按钮）；
   - 你的**网站邮箱**和密码——启动器登录时用户名填的就是邮箱。
3. 首次在启动器登录成功后，系统会**自动**为你的账号创建一个 1:1 的游戏角色，
   UUID 可以在「游戏账号管理」页查看和复制。
4. 一个账号只有一个游戏身份；改名有 30 天冷却（旧名保留 30 天），在
   「游戏账号管理」页操作。

## HMCL（Hello Minecraft! Launcher）

1. 打开 HMCL，左侧栏点 **设置**；
2. 切到 **账户** 标签 → 点 **添加账户** → 选择 **外置登录**（authlib-injector）；
3. 认证服务器填 `https://auth.example.com/api`（以站点页面显示的为准）；
4. 用户名填**网站邮箱**，密码填网站密码，点击登录；
5. 登录成功后启动器会显示你的角色名与皮肤；选好版本直接启动即可。

## PCL2（Plain Craft Launcher 2）

1. 打开 PCL2 → **设置** → **启动器** → **游戏账户**；
2. 账户类型选 **认证服务器**（外置登录）；
3. 认证服务器地址填 `https://auth.example.com/api`；
   **注意：PCL2 默认只接受 HTTPS 地址**，如果你的服主只给了 `http://` 地址，
   让服主按部署文档配好 TLS 再试；
4. 用户名填**网站邮箱**，密码填网站密码，登录；
5. 回到主页选版本启动。

## Prism Launcher

1. 打开 Prism Launcher，右上角 **账户** 图标 → **管理账户** → **添加账户**；
2. 账户类型下拉选 **Authlib-Injector**；
3. 认证服务器填 `https://auth.example.com/api`，Prism 会拉取服务器元数据；
4. 用户名填**网站邮箱**，密码填网站密码，登录；
5. 启动对应实例即可，皮肤与披风自动同步。

## 常见问题

| 现象                      | 原因与处理                                                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 登录报「邮箱尚未验证」    | 先去网站收件箱点验证链接，再用同一账号登录启动器                                                                          |
| 登录报密码错误            | 用户名必须填**网站邮箱**（不是角色名）；密码是网站密码，可在网站登录页用「忘记密码」重设                                  |
| 皮肤没同步到游戏          | 上传成功后重启启动器 / 重新进服；皮肤只支持原版尺寸（64×32 / 64×64 PNG），大图会被拒绝                                    |
| 想换披风                  | 披风功能可能需要先用积分在成长中心解锁（解锁前上传/切换披风返回 403），皮肤不受影响                                       |
| 想在公共电脑登出          | 启动器里删除账户即可；如需彻底吊销该设备令牌，在启动器重新登录时使用「invalidate/登出」操作（当前网站侧不提供设备管理页） |
| 报「进服失败 / 无效会话」 | 进服需要**客户端和服务器两侧都注入 authlib-injector**；客户端按本指南配置即可，服端问题找服主                             |
